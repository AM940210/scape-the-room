# 🗝 Escape the Room - Web Game

This is a simple, interactive **Escape Room game** built using **HTML, CSS, and JavaScript**.
The game is structured across multiple rooms, each with unique puzzle the player must solve to advance.

## 🚪 Game Structure

### 🔐 Room 1: Hidden Clues
- Players must find ** 3 hidden numbers ** by clicking on objects.
- Once all clues are discovered, they enter a 3-digit code to unlock the door.

### 🖼 Room 2: Image Challenge
- A ** Slideshow of images ** runs with a 60-second timer.
- Players must click the correct image (randomized each time) to enter the next room.

### 🧩 Room 3: Matching Items
-- Players drag and drop items (🔑 📘 🔨) into the correct boxes.
-- Matches must be made without seeing which item belongs where.

### 🏆 Victory Screen
- Diplays a congratulatory message and image when all puzzle are solved.


---


## ▶️ How to play
1. ** Open index.html in your browser ** to begin the game.
2. Explore objects, find clues, solve puzzles.
3. Complete all 3 rooms to escape successfully.

## 💡 Tips
- Be quick - some rooms are timed!
- Not all clues are immediately visible - interact with everthing.
- Use logic and observation to match items correctly.
